MittiAI · Track 404

AI approach — Google AI integration

Gemini does the heavy lifting four ways

👁️ Multimodal vision diagnosis

Gemini vision reads field photos (blurry, low-light tolerant) → structured JSON via responseSchema: disease, confidence, severity, treatment.

📊 Data-fused advisory engine

Soil nutrients + NDVI trend + 14-day forecast are composed into one prompt → structured regenerative calendar JSON.

🗣️ Multilingual voice loop

Web Speech STT → Gemini answers in the farmer's language → TTS readout. No literacy barrier.

📣 Officer bulletin drafting

Gemini composes district early-warning bulletins from live outbreak facts — SMS/IVR ready.

Every call: timeout + demo-mode fallback — the product never hard-fails on stage.
